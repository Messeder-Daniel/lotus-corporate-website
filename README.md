# Lótus Indústria e Comércio — Site Institucional

Projeto de site institucional desenvolvido para a **Lótus Indústria e Comércio**, utilizando a plataforma **Wix**.

Este projeto representa uma fase anterior da minha trajetória em tecnologia, quando eu atuava principalmente com **design digital, organização de conteúdo e ferramentas no-code**. Foi também uma das experiências que despertaram meu interesse em desenvolvimento web e, posteriormente, em desenvolvimento frontend e full stack.

## 🌐 Site publicado

https://www.industrialotus.com/

## 🎯 Objetivo do projeto

Criar uma presença digital profissional para a empresa, apresentando de forma clara:

* produtos e soluções;
* informações institucionais;
* canais de contato;
* identidade visual da marca;
* acesso rápido ao atendimento comercial.

## 👨‍💻 Minha participação

Fui responsável por:

* estruturação das páginas;
* organização da navegação;
* aplicação da identidade visual da empresa;
* criação e organização do conteúdo;
* adaptação dos materiais para ambiente web;
* configuração de elementos visuais e interativos;
* manutenção e atualização do site;
* publicação utilizando a plataforma Wix.

## 🛠️ Ferramentas e tecnologias

* Wix
* Web Design
* UX/UI
* Desenvolvimento No-Code
* Design Responsivo
* Arquitetura da Informação
* Organização de Conteúdo

## 🧠 Aprendizados

Esse projeto foi importante para entender, na prática, como decisões de design impactam a experiência de quem utiliza um site.

Também tive contato com conceitos como:

* hierarquia visual;
* navegação;
* organização de informações;
* adaptação de layouts para diferentes dispositivos;
* comunicação entre necessidades comerciais e experiência digital.

Com o tempo, essa experiência contribuiu para meu interesse em compreender também o que acontece por trás das interfaces, levando meus estudos para desenvolvimento frontend, backend e aplicações full stack.

## 📈 Evolução profissional

Minha trajetória começou com maior proximidade de design e ferramentas no-code.

A partir dessa experiência, passei a estudar desenvolvimento de software e hoje venho construindo projetos utilizando tecnologias como Java, Spring Boot, TypeScript, React, Go, Rust, SQL, PostgreSQL e Docker.

Este projeto representa, portanto, um dos primeiros passos dessa evolução.
